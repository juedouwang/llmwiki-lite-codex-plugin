## Purpose
让用户在同一个科研项目的代码页管理同仓库的已有工作树，明确区分进入目录与切换分支，保留各目录未提交内容和现有 Git 安全保护，不拆分科研资料。

## ADDED Requirements
### Requirement: 同项目选择已有工作树
系统 SHALL 在多个工作树时提供“选择工作树”，标识目录、分支、当前与注册目录；单工作树不增加无用控件。进入工作树只改变代码页操作目标，不改变科研项目和注册目录，不执行 checkout。
#### Scenario: 两个目录均有未提交内容
- **WHEN** 用户在同项目双向进入已有工作树
- **THEN** 代码状态与元数据对应选中目录，两个目录的 HEAD、索引与文件均不受导航影响
#### Scenario: 刷新与历史返回
- **WHEN** 用户刷新带工作树上下文的 URL 或通过浏览器后退返回
- **THEN** 恢复对应目录，不把迟到请求或缓存混入另一目录；未确认 Git 输入沿用离页保护

### Requirement: 被占用分支提供可用入口
系统 SHALL 保留被其他工作树占用分支的禁止检出状态，并在目标可用时提供“进入所在工作树”；不可用目标显示原因且不得假装进入成功。
#### Scenario: 进入已检出分支
- **WHEN** 用户点击被占用分支旁的“进入所在工作树”
- **THEN** 仍是同一项目，展示占用目录和该分支，原目录分支不变
#### Scenario: 游离与失效目录
- **WHEN** 列表含游离 HEAD 或已移走的工作树
- **THEN** 游离目录可浏览且保留现有写入限制；失效目录不可选择，失效旧链接报错并提供返回注册目录

### Requirement: 目录绑定与写入隔离
系统 MUST 只接受注册仓库登记的工作树，拒绝任意路径或其他项目的标识；全部读写绑定选中目录。预览与文件选择不得跨目录重用，共享仓库锁和锁内重校验不得削弱。
#### Scenario: 选中工作树保存
- **WHEN** 用户在关联工作树预览并确认保存一个文件
- **THEN** 只保存该目录所选文件，其他目录的未提交内容与暂存区不变，合并和远端检查状态不串用
#### Scenario: 绑定失效或跨树重放
- **WHEN** 预览被另一工作树使用，或确认前目标移走、Git 绑定改变
- **THEN** 操作拒绝，不能静默回退到注册目录执行
