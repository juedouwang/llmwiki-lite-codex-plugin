# 科研工作台待办优化

## Why
落实 2026-09-21 用户在野人工作台 project-d794d170 科研进度的 7 项任务及《科研记录优化安排》。产品宗旨：简单、优雅、好用。

## What Changes
- 项目切换下拉只保留项目选择；点击外部关闭。项目管理右键/更多菜单重命名和移除。
- 网站进程内保持用户当前项目；默认项目只在需要初始化选择时生效。
- 科研进度用任务描述、截止日、优先级，支持描述粘贴截图；保留待办/已完成。
- 笔记/日报/周报统一自动保存与 Markdown 实时图片编辑，移除冗余按钮，立即同步标题。
- 代码图标回批准原型；已有多个工作树可以安全操作当前工作树。
- 在自动整理配置处解释定时任务与会话关联，不自动开启任何计划或读取授权外的对话。

## Capabilities
### New Capabilities
- `workbench-task-refinements`: 本轮明确交互和兼容性验收。

## Impact
Python 标准库、原生前端；不新增依赖、不改安装缓存、不发布、不改变真实科研任务状态。
