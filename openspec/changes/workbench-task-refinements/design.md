# 设计

本轮在现有实现上收敛操作，不替换整体架构。批准 HTML 是图标与视觉参考，用户本轮具体要求覆盖旧设计。

1. 展示名称独立于项目 ID 和存储路径，移除仅注销注册；右键菜单同时提供键盘和更多按钮入口，移除二次确认。
2. 用每次网站启动的随机标识隔离浏览器当前项目，显式进入项目后保持选择，全局页面不读 agent 的 current_project_id 来覆盖。缓存预取不可切换选择；重命名/移除同步失效缓存。
3. 进度兼容旧 checkpoint/next_step/日期/状态和自动总结，不覆盖手写内容；UI 用描述、可选 ddl 和优先级，完成状态仍由用户控制。默认视窗从今天开始，未完成且有截止日的任务显示今天至截止日的跨度；逾期显示在今天列，跨窗口条裁剪但保留真实日期提示。此跨度是只读的剩余时间展示，不回写开始日。优先级与日期桌面等宽等高两列，快捷日期在日期字段下方，窄屏单列。
4. 编辑 Markdown 时图片在正文可见，原始 Markdown 不损坏；保持 IME、撤销、粘贴/拖入、安全附件路由和离页保存保护。自动保存失败不能显示已保存。报告确认发布仍是显式操作。
5. 多工作树操作解析当前工作树根和共同 Git 目录；共享锁覆盖 refs 写入，校验操作令牌及占用分支，原有 hooks/签名/凭据限制继续成立。
6. 自动整理页面解释“何时运行”的宿主计划与“哪些资料”的项目会话关联是两回事；配置保存不冒充计划已连接。保存设置时在现有锁内校验新选择；撤销旧授权只处理仍注册项目，已注销项目不再解析，也不访问其保留文件。新请求显式选择已注销项目仍中文拒绝，不写配置；保留现存授权、时间与运行回执。

## 验证
所有写入测试用临时项目/仓库，多工作树用本地临时仓库。按模块并行验证后整合浏览器验收，不修改真实待办/笔记、不自动提交。

## 共享计划与跨度条细节（2026-09-21）
共享计划已经按每轮最新设置取材，不新增后台或第二套调度。UI只在未连接时保留首次连接主按钮，已连接的维护入口收进说明；项目选择/授权变更保存后自动用于下一轮。调整日程时明确需要同步同一个官方计划，未保存时禁止复制旧指令；连接指令不再固定项目名单、配置版本或18:00。新注册项目默认加入参与列表，重复注册或重命名不恢复已取消选择；只继承现存取材宿主开关，不自行启用关闭的取材、恢复暂停计划或回填授权前历史。跨度条去掉深色左边框，保留柔和底色、文字及截断边角。

## 新项目默认参与与日报最小修复（2026-09-21）
注册/注销在已有注册锁内同步报告选择，不调用会再次取同一非重入锁的设置保存函数。真正新项目追加到既有选择，取消的其他项目不变；注册不扫描、不生成。注销仅清理配置的项目 ID 和活动库路径，不访问注销项目保留文件；读取历史设置时也过滤已注销 ID，防止旧配置让整个 report_plan 抛错。执行端回执、时刻、总开关和现存项目授权保持不变，不修改官方计划指令。

当日报告用现有 plan/sources/finish 协议真实取材并由宿主撰写，保存草稿、不发布、不改 Todo。手工报告试跑不等同于定时触发或完整三阶段成功；历史日志未记录具体异常时只能说明复现的缺陷与回执一致，不能冒称唯一根因已确认。
