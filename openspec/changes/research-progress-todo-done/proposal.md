## Why

科研工作跨天后容易丢失上下文；已完成事项也需要保留，供详细日报与周报回顾。沿用已有任务时间轴，把 Todo、Done 和“继续上次”整理成同一个任务功能，不重建笔记或另造摘要管理系统。

## What Changes

- 固定产品分工：任务保留简短进度，日报展开一天的工作过程，知识库沿用 LLM Wiki 解释项目架构与关键知识；本次只实施任务功能。
- 保留现有四种任务状态、关联笔记与两周/四周查看能力；补齐完成时间、Done 留存、重新打开及项目列表摘要。已确认整站原型增量改为默认周视图和单张继续上次摘要，不改变人工/自动字段语义。
- 任务名称、排期、状态由用户控制；自动上下文与人工上下文分开保存，人工修订优先，清空也不能被自动内容填回。
- “继续上次”只展示未完成任务及其有效上下文，不引入第二套任务、完成率、自动拆解或自动排期。
- 让页面及任务保存与摘要生成解耦：仅接收和展示已生成的摘要，不在读取、保存、Hook 或 Git 操作中等待模型。
- 本次交付自动上下文的接入接口和保护机制；真正无人值守的采集、模型执行与定时调度属于后续独立规格。未接通时如实显示，不能宣称“自动整理已开启”。

### 已确认界面对齐增量

共享壳引用第二份 design D-11；本份只改科研进度的内容区及默认项目入口。既有完成项保留，新增 tasks 第 6 节；不是推翻原交付，也不把日报生成塞回本份。

### Modified Capabilities

无。当前 OpenSpec 尚无已发布能力规格。
